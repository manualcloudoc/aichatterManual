# 문서봇 히스토리 보기



***



{% hint style="success" %}
사용자가 생성하거나 '소스 편집 허용' 또는 '전체 허용' 권한으로 공유 받은 문서봇만 히스토리를 조회할 수 있습니다.
{% endhint %}



### 문서봇 히스토리 조회하기

&#x20;다음은  문서봇의 히스토리를 조회하는 방법입니다.



1. ‘[문서봇 상세 화면 살펴보기](../undefined-1/undefined-2/undefined-1.md)’의 내용을 참고하여 히스토리를 조회할 문서봇의 ‘상세 화면’으로 이동합니다.



2. '문서봇 상세' 화면에서 **히스토리** 버튼을 클릭합니다.

<div align="left"><figure><img src="../../.gitbook/assets/image (234).png" alt=""><figcaption></figcaption></figure></div>



3. 다음과 같은 ‘히스토리’ 화면이 나타납니다.

<div align="left"><figure><img src="../../.gitbook/assets/image (235).png" alt=""><figcaption></figcaption></figure></div>



'히스토리' 화면에는 문서봇 관련 작업 내역이 ‘하루’ 단위로 묶여서 표시되고, 최근 내역일수록 상단에 위치합니다.



***

### 문서봇 히스토리 화면 살펴보기



문서봇 ‘히스토리’ 화면은 다음 부분으로 구성되어 있습니다.

<figure><img src="../../.gitbook/assets/image (236).png" alt=""><figcaption></figcaption></figure>



**❶ 필터**

히스토리 내역 중에서 특정 작업 내역만 표시하도록 하는 조건을 설정하는 필터입니다. [문서봇 히스토리 검색하기](undefined-6.md#undefined-2)에서 필터의 종류와 사용 방법을 소개합니다.



**❷ 날짜**

문서봇이 수정되었거나 문서봇 채팅이 실행된 날짜를 표시합니다. 같은 날에 실행된 작업은 하나로 묶여 표시되며 날짜는 다음 기준에 따라 표시됩니다.



* **오늘, 어제**: ‘오늘’, ‘어제’로 표시됩니다.
* **2 \~ 7일 전**: ‘○일 전’ 형식으로 표시됩니다. (예: 4일 전)
* **8일 이전**: 해당 월로 표시됩니다. (예: 9월)
* **이전 연도**: 해당 연도로 표시됩니다. (예: 2024년)



➌ **날짜/시간**

해당 작업이 실행된 날짜와 시간을 표시합니다. 날짜와 시간이 표시되는 형식은 다음 기준에 따라 달라집니다.

* **오늘인 경우**: 오전/오후 hh:mm (예: 오전 11:00)
* **그 외**: YYYY-MM-DD 오전/오후 hh:mm (예: 2020-10-13 오전 06:13)

&#x20;

**❹ 작업 종류**

문서봇에서 실행된 작업이 표시됩니다. 표시되는 작업 종류는 다음과 같습니다.

<table><thead><tr><th width="154.66668701171875">작업 유형</th><th width="507.77777099609375">작업 종류</th></tr></thead><tbody><tr><td><strong>채팅 관련</strong></td><td>채팅</td></tr><tr><td><strong>소스 관련</strong></td><td>소스 추가, 소스 삭제, 비공개로 소스 변경, 소스 이름 변경</td></tr><tr><td><strong>문서봇 공유 관련</strong></td><td>공유 설정, 공유 해제, 사용 권한 변경</td></tr><tr><td><strong>문서봇 위젯 관련</strong></td><td>위젯 만들기, 위젯 업데이트, 위젯 삭제</td></tr><tr><td><strong>문서봇 관련</strong></td><td>문서봇 만들기, 문서봇 편집</td></tr><tr><td><strong>추천 질문 관련</strong></td><td>추천 질문 추가, 추천 질문 변경, 추천 질문 삭제</td></tr></tbody></table>



**❺ 상세 작업 내용**

작업을 실행한 사용자와 작업에 대한 상세 내역이 표시됩니다. 사용자가 본인이 아닌 경우에는 굵은 글씨체로 표시되며 클릭하면 해당 사용자 정보를 보여주는 창이 팝업됩니다.



**➏ 해당 페이지로 이동**

작업과 관련된 화면으로 이동하는 링크입니다. 예를 들어, **추천 질문 추가** 작업은 ‘추천 질문 만들기’ 화면으로, **소스 추가** 작업은 ‘문서봇 상세’ 화면으로 이동합니다.



***

### 문서봇 히스토리 검색하기

‘히스토리’ 화면 상단의 필터를 사용해 조건을 설정하면, 해당 조건에 맞는 문서봇 작업 내역만 조회할 수 있습니다.

<div align="left"><figure><img src="../../.gitbook/assets/image (237).png" alt="" width="310"><figcaption></figcaption></figure></div>



필터는 **카테고리**, **사용자**, **활동한 날짜** 세가지로 구성되어 있으며, 각 필터의 항목을 선택하면 해당 항목에 해당하는 작업 내역이 바로 표시됩니다.&#x20;



각 필터의 기능과 선택할 수 있는 항목은 다음과 같습니다.



**❶ 카테고리 필터**

표시할 작업의 **카테고리**를 선택하는 필터입니다. 선택한 카테고리에 따라 작업 종류를 더 세부적으로 선택할 수 있는 ‘세부 분류’ 필터가 오른쪽에 추가됩니다.

<div align="left"><figure><img src="../../.gitbook/assets/image (238).png" alt="" width="488"><figcaption></figcaption></figure></div>



각 카테고리의 '세부 분류' 필터에서 선택할 수 있는 작업은 다음과 같습니다.

<table><thead><tr><th width="110.22222900390625">카테고리</th><th width="445.55560302734375">세부 분류</th></tr></thead><tbody><tr><td><strong>소스</strong></td><td>소스 추가, 소스 삭제, 비공개로 소스 변경, 소스 이름 변경</td></tr><tr><td><strong>공유</strong></td><td>공유 설정, 공유 해제, 사용 권한 변경</td></tr><tr><td><strong>위젯</strong></td><td>위젯 만들기, 위젯 업데이트, 위젯 삭제</td></tr><tr><td><strong>문서봇</strong></td><td>문서봇 만들기, 문서봇 편집</td></tr><tr><td><strong>추천 질문</strong></td><td>추천 질문 추가, 추천 질문 변경, 추천 질문 삭제</td></tr></tbody></table>



**❷ 사용자 필터**

특정 **사용자**가 수행한 작업 내역만 표시하도록 사용자를 선택하는 필터입니다. 필터를 클릭하면 사용자를 검색할 수 있는 검색 창이 나타납니다. 검색  창에 문자를 입력하면 해당 문자가 포함된 사용자 목록이 표시되며, 목록에서 원하는 사용자를 선택합니다.

<div align="left"><figure><img src="../../.gitbook/assets/image (239).png" alt="" width="221"><figcaption></figcaption></figure></div>

&#x20;

**➌ 활동한 날짜 필터**

**특정 기간** 동안 실행된 작업 내역만 표시하도록 기간을 지정하는 필터입니다. 필터를 클릭하면 기간을 선택할 수 있는 항목이 표시되며, 항목 중에서 기간을 선택하거나 ‘**사용자 지정**’을 선택해 원하는 기간을 직접 입력할 수 있습니다.

<div align="left"><figure><img src="../../.gitbook/assets/image (240).png" alt="" width="448"><figcaption></figcaption></figure></div>



다음은 **지난 30일 동안의 문서봇 채팅 내역만 표시**되도록 필터를 설정했을 때 표시되는 화면입니다.

<div align="left"><figure><img src="../../.gitbook/assets/image (241).png" alt=""><figcaption></figcaption></figure></div>



필터 설정 시 오른쪽에 표시되는 **필터 지우기**를 클릭하면 필터가 초기화되고 모든 히스토리 내역이 표시됩니다.
