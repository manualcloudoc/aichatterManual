  권한으로 문서봇을 공유 받은 경우, 해당 문서봇을 사용해 채팅할 수 있습니다. 새로운 문서봇 채팅을 시작하거나 기존 문서봇 채팅을 이어서
  하는 방법을 살펴봅니다.

# 문서봇 채팅하기

***



{% hint style="success" %}
&#x20;문서봇 채팅은 문서 기반 정보의 정확한 검색과 응답에 최적화된 기능으로 대화의 맥락을 기억하는 메모리 기능은 지원하지 않습니다. 또한, 텍스트 기반 답변만 제공되므로 데이터 시각화나 파일 생성은 지원하지 않습니다.
{% endhint %}



### 문서봇 채팅 시작하기

문서봇 채팅을 시작하는 방법은 다음과 같습니다.



1. 현재 문서봇 화면이 아닌 경우 aichatter 화면 상단의 메뉴에서 **문서봇**을 클릭합니다.

<div align="left"><figure><img src="../../../.gitbook/assets/image (242).png" alt=""><figcaption></figcaption></figure></div>



2. '모든 문서봇' 화면이 표시됩니다. 문서봇 목록에서 채팅할 문서봇으로 커서를 올려 **호버** 아이콘이 나타나면 **채팅** 아이콘을 클릭합니다.

<div align="left"><figure><img src="../../../.gitbook/assets/image (243).png" alt=""><figcaption></figcaption></figure></div>



3. 문서봇 채팅 화면으로 이동합니다. 채팅 화면의 중앙에는 문서봇 이름과 설명이 표시되고, 왼쪽 상단에 표시된 문서봇 이름을 클릭하면 문서봇 관련 메뉴를 볼 수 있습니다.

<div align="left"><figure><img src="../../../.gitbook/assets/image (245).png" alt=""><figcaption></figcaption></figure></div>

{% hint style="success" %}
문서봇 이름을 클릭했을 때 표시되는 각 메뉴의 기능은 다음과 같습니다.



* **새 채팅**: 새로운 문서봇 채팅을 시작합니다. 기존 대화의 맥락이 초기화되며 새로운 주제로 질문할 수 있습니다.
* **문서봇 정보**: 문서봇의 기본 정보(이름, 생성자, 공유자, 설명, 기본 언어 모델, 요청 사항)를 보여주는 창이 팝업됩니다.
* **상세 보기**: 문서봇의 상세 정보와 소스 목록을 볼 수 있는 ‘상세 화면’으로 이동합니다.
* **문서봇 공유**: 문서봇을 공유할 사용자를 지정할 수 있는 창이 팝업됩니다.
* **사이드바에서 보이기/숨기기**: 채팅 화면의 사이드바에 문서봇을 표시하거나 숨깁니다.
{% endhint %}



4. 채팅 창에 질문을 입력한 후 **Enter**를 누르거나 전송 버튼 ![](/broken/files/64EQvRM631pccHRT93MW)을 클릭합니다. 채팅 창 위에 추천 질문이 표시되어 있는 경우에는 원하는 질문을 클릭해 질문을 보낼 수도 있습니다.

<div align="left"><figure><img src="../../../.gitbook/assets/image (487).png" alt="" width="493"><figcaption></figcaption></figure></div>



5. 답변 창에 생성된 답변이 표시됩니다. 문서봇에 등록된 **문서** 소스를 참고하여 생성된 답변의 경우, 하단에 해당 소스 파일의 이름이 표시됩니다. ‘공개’로 등록된 소스는 다운로드가 가능합니다.

<div align="left"><figure><img src="../../../.gitbook/assets/image (423).png" alt="" width="563"><figcaption></figcaption></figure></div>

{% hint style="success" %}
답변 아래에 표시되는 아이콘은 다음과 같은 기능을 제공합니다.



* <img src="/broken/files/rkK6CcRGg2UzVqtbZhge" alt="" data-size="original"> **복사:** 답변 전체 내용을 클립보드로 복사합니다. 문서 작성이나 메신저 등에 빠르게 붙여넣기 할 때 유용합니다.
* ![](/broken/files/Dd0PHgSOCDpXOAVNo38e) **재생성:** 동일한 질문으로 AI에게 다시 답변을 요청합니다. 다른 관점이나 추가 사례를 보고 싶을 때 사용하면 편리합니다.
* ![](<../../../.gitbook/assets/image (402).png>) **공유:** 현재 채팅이나 선택한 채팅을 동료와 공유할 수 있습니다.
* **피드백 버튼(**   ![](<../../../.gitbook/assets/image (403).png>)  **좋아요**,  ![](/broken/files/pFn255TsUoL6Q93PVkVE) **싫어요):** 답변에 대한 만족도를 표현할 수 있는 버튼입니다. 사용자 평가는 모델 개선에 반영됩니다.
{% endhint %}



6. 답변이 만족스럽지 않은 경우에는 다른 언어모델을 선택해 다시 질문할 수 있습니다.

<div align="left"><figure><img src="../../../.gitbook/assets/image (405).png" alt="" width="532"><figcaption></figcaption></figure></div>



7. 질문의 핵심 내용을 바탕으로 문서봇 채팅의 제목이 생성되고, 이 제목으로 사이드바의 채팅 목록 최상단에 추가됩니다.

<div align="left"><figure><img src="../../../.gitbook/assets/image (488).png" alt=""><figcaption></figcaption></figure></div>

{% hint style="success" %}
사이드바의 채팅 목록에 추가된 문서봇 채팅은 일반 채팅과 동일하게  다음 작업을 수행할 수 있습니다.



* 문서봇 채팅 이름 변경 및 이모지(아이콘) 추가
* 문서봇 채팅 삭제
* 문서봇 채팅 상단 고정



이러한 작업을 수행하는 방법은 [채팅 관리하기](../../undefined/undefined-9/)를 참고합니다.
{% endhint %}



8. 기존 대화를 끝내고 새로운 대화를 시작하려면, 화면 왼쪽 상단에서 문서봇 이름을 클릭한 후 **새 채팅** 메뉴를 선택합니다.

<div align="left"><figure><img src="../../../.gitbook/assets/image (247).png" alt=""><figcaption></figcaption></figure></div>

### 이전 문서봇 채팅 불러오기



문서봇 채팅도 일반 채팅과 마찬가지로 채팅 내용이 자동 저장되고, 질문의 핵심 내용으로 제목이 생성되어 사이드 바의 채팅 목록에 추가됩니다. 사이드 바에서 문서봇 채팅 항목을 클릭하면 해당 채팅의 내용이 답변 창에 표시됩니다. 단, 문서봇 채팅은 메모리 기능을 지원하지 않으므로 이전 대화 내용을 참조한 질문에는 답변할 수 없습니다.



저장된 문서봇 채팅을 불러와 채팅하는 방법은 다음과 같습니다.



1. 채팅 화면 사이드바의 채팅 목록에서 가져올 문서봇 채팅을 선택합니다. 해당 채팅의 대화 내용이 답변 창에 표시됩니다.



2. 질문을 채팅 창에 입력한 후 **Enter**를 누르거나 **전송** 버튼<img src="/broken/files/P2iLhmW6agteGIPVkpKU" alt="" data-size="line">을 클릭합니다.

<div align="left"><figure><img src="../../../.gitbook/assets/image (246).png" alt=""><figcaption></figcaption></figure></div>
