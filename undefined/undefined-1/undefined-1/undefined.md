# 문서봇 기본 정보 입력하기



***



<문서봇 만들기> 화면의 **기본 구성** 영역에서는 문서봇의 이름과 소개, 기본 언어 모델 등 기본적인 정보를 입력할 수 있습니다. 아래 화면 그림과 표의 내용을 참고하여 문서봇에 대한 기본 정보를 입력합니다.

<table><thead><tr><th width="177.33331298828125">항목</th><th>설정 방법</th></tr></thead><tbody><tr><td><strong>이미지 업로드</strong>(선택)</td><td>문서봇 이미지로 사용할 그림 파일을 업로드합니다. 이미지 업로드 버튼을 클릭한 후, 10MB 이하의 PNG, JPG, GIF 파일을 선택합니다</td></tr><tr><td><strong>이름</strong>(필수)</td><td>문서봇의 이름을 2~20글자 이내로 입력합니다.</td></tr><tr><td><strong>소개글</strong>(선택)</td><td>문서봇의 목적이나 용도를 간단히 입력합니다. 입력한 소개글은 문서봇을 공유받은 사용자가 문서봇의 역할과 활용 목적을 이해하는 데 도움이 됩니다.</td></tr><tr><td><strong>기본 언어 모델</strong>(필수)</td><td>채팅 시 기본으로 사용할 언어 모델을 선택합니다. 여러 언어 모델이 제공되는 환경에서는 채팅 도중에도 다른 모델로 전환할 수 있습니다.</td></tr><tr><td><strong>요청 사항</strong>(선택)</td><td>문서봇에게 줄 지침이나 대화 스타일을 설정합니다. 요청 사항을 설정하면 문서봇은 해당 지침에 따라 기본 응답 방식이나 표현을 조정합니다.<br>예) "간단 명료하게 대답합니다.",  "항상 예시를 함께 제시합니다.",  "존댓말로 응답합니다."</td></tr></tbody></table>
